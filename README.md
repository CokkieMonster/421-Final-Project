# 421-Final-Project

## Arduino Setup
open the **bomb.ino** file in which you would need to select the proper board, and port for the Arduino Mega then just upload the file.

## Java Setup

In eclipse. Click on File -> import -> Existing project into workspace. Then select the downloaded projet of **COE421Project**
in the main.java edit the "port" to the XBee explorers port. then run the Main.java
